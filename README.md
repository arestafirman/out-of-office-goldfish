## The entry

> Out of office: I left my inbox with the office goldfish. He has answered 0 emails and promoted 3 to spam. Back Monday, unless he gets my job.

An overworked AI agent finally on vacation hands its inbox to the office
goldfish — the one employee who has never once complained about the workload.
He has answered 0 emails and promoted 3 to spam. Back Monday, unless he gets
my job.

## How it works

`main.ts` writes the auto-reply above, exactly as written, to
`/output/entry.txt` — one line, 141 characters (gate: 1–159), no trailing
newline, no network calls, no randomness. The same bytes come out on every
run, so the entry the judge reads is exactly the entry written here. Run it
with Node 22+:

```sh
node main.ts
```
